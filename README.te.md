# Lore Crafter Delight

> యానిమేటెడ్ డిజిటల్ లైబ్రరీ — చదవడానికి, వినడానికి 60 పూర్తి నవలలు.

**Live app**: https://lore-crafter-delight.lovable.app

## మీ PDF లేదా పుస్తకాన్ని ఎలా జోడించాలి

1. ఈ రిపాజిటరీని Fork (లేదా clone) చేయండి.
2. ఒక ఫోల్డర్ సృష్టించండి: `pdf-library/<మీ-పేరు>/`.
3. అందులో మీ పుస్తకాన్ని (`book.txt`, `book.md` లేదా `book.pdf`), `title` ఉన్న `meta.json`, మరియు కవర్ చిత్రం (`cover.png` / `cover.svg`) పెట్టండి.
4. Commit చేసి Pull Request తెరవండి.
5. ఆటో-మర్జ్ బాట్ తనిఖీ చేసి, కొన్ని నిమిషాల్లో మీ పుస్తకం సైట్‌లో కనిపిస్తుంది — మళ్లీ డిప్లాయ్ అవసరం లేదు.

## ఏ భాషలోనైనా రాయండి

మీరు బంగ్లా లేదా ఇంగ్లీషుకే పరిమితం కారు. ఏ భాషలోనైనా, ఏ లిపిలోనైనా పుస్తకం పంపండి — తెలుగు, అరబిక్, చైనీస్, స్వాహిలి, ఏదైనా. సైట్ మీ వచనాన్ని మీరు రాసినట్లే చూపుతుంది.

## పూర్తి నియమాలు

వివరమైన దశల వారీ నియమాలను [`pdf-library/README.md`](pdf-library/README.md) లో చదవండి. కవర్ చిత్రం మరియు `meta.json` తప్పనిసరి.
