# Lore Crafter Delight

> Una biblioteca digitale animata — 60 romanzi completi da leggere e ascoltare.

**Live app**: https://lore-crafter-delight.lovable.app

## Come aggiungere il tuo PDF o libro

1. Fai un fork di questo repository (o clonalo).
2. Crea una cartella: `pdf-library/<il-tuo-nome>/`.
3. Metti dentro il tuo libro (`book.txt`, `book.md` o `book.pdf`), un `meta.json` con `title` e un'immagine di copertina (`cover.png` / `cover.svg`).
4. Esegui il commit e apri una Pull Request.
5. Il bot di unione automatica verifica e il tuo libro appare sul sito in pochi minuti — senza nuovo deploy.

## Scrivi in qualsiasi lingua

Non sei limitato al bengalese o all'inglese. Invia un libro in qualsiasi lingua e scrittura — italiano, arabo, cinese, swahili, qualsiasi. Il sito mostra il tuo testo esattamente come l'hai scritto.

## Regole complete

Leggi le regole dettagliate passo passo in [`pdf-library/README.md`](pdf-library/README.md). Immagine di copertina e `meta.json` sono obbligatori.
