# Lore Crafter Delight

> ספרייה דיגיטלית מונפשת — 60 רומנים שלמים לקריאה ולהאזנה.

**Live app**: https://lore-crafter-delight.lovable.app

## איך להוסיף את ה-PDF או הספר שלך

1. עשו Fork למאגר הזה (או שכפלו אותו).
2. צרו תיקייה: `pdf-library/<השם-שלכם>/`.
3. שימו בה את הספר שלכם (`book.txt`, `book.md` או `book.pdf`), קובץ `meta.json` עם `title`, ותמונת כריכה (`cover.png` / `cover.svg`).
4. בצעו Commit ופתחו Pull Request.
5. בוט המיזוג האוטומטי בודק אותו, והספר שלכם מופיע באתר תוך דקות — בלי פריסה מחדש.

## כתבו בכל שפה

אינכם מוגבלים לבנגלית או לאנגלית. שלחו ספר בכל שפה ובכל כתב — עברית, ערבית, סינית, סווהילית, כל דבר. האתר מציג את הטקסט שלכם בדיוק כפי שכתבתם.

## כללים מלאים

קראו את הכללים המפורטים שלב אחר שלב ב־[`pdf-library/README.md`](pdf-library/README.md). תמונת כריכה ו־`meta.json` הם חובה.
