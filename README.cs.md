# Lore Crafter Delight

> Animovaná digitální knihovna — 60 plných románů ke čtení i poslechu.

**Live app**: https://lore-crafter-delight.lovable.app

## Jak přidat své PDF nebo knihu

1. Vytvořte fork tohoto repozitáře (nebo jej naklonujte).
2. Vytvořte složku: `pdf-library/<vaše-jméno>/`.
3. Vložte do ní svou knihu (`book.txt`, `book.md` nebo `book.pdf`), soubor `meta.json` s polem `title` a obrázek obálky (`cover.png` / `cover.svg`).
4. Zapište změny a otevřete Pull Request.
5. Bot pro automatické sloučení je zkontroluje a vaše kniha se během minut objeví na webu — bez nového nasazení.

## Pište v jakémkoli jazyce

 Nejste omezeni na bengálštinu nebo angličtinu. Pošlete knihu v jakémkoli jazyce a písmu — česky, arabsky, čínsky, svahilsky, jakkoli. Web zobrazí váš text přesně tak, jak jste jej napsali.

## Úplná pravidla

Přečtěte si podrobná pravidla krok za krokem v [`pdf-library/README.md`](pdf-library/README.md). Obrázek obálky a `meta.json` jsou povinné.
