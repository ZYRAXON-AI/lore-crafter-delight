# Lore Crafter Delight

> இயங்கும் மின்னணு நூலகம் — படிக்கவும் கேட்கவும் 60 முழு நாவல்கள்.

**Live app**: https://lore-crafter-delight.lovable.app

## உங்கள் PDF அல்லது புத்தகத்தை எப்படிச் சேர்ப்பது

1. இந்தக் களஞ்சியத்தை Fork (அல்லது clone) செய்யுங்கள்.
2. ஒரு கோப்புறையை உருவாக்குங்கள்: `pdf-library/<உங்கள்-பெயர்>/`.
3. அதில் உங்கள் புத்தகத்தை (`book.txt`, `book.md` அல்லது `book.pdf`), `title` கொண்ட `meta.json`, மற்றும் அட்டைப் படம் (`cover.png` / `cover.svg`) வையுங்கள்.
4. Commit செய்து Pull Request திறங்கள்.
5. தன்னியக்க இணைப்பு போட் சரிபார்த்து, சில நிமிடங்களில் உங்கள் புத்தகம் தளத்தில் தோன்றும் — மீண்டும் வெளியிட தேவையில்லை.

## எந்த மொழியிலும் எழுதுங்கள்

நீங்கள் வங்காளம் அல்லது ஆங்கிலத்திற்கு மட்டும் வரம்பிடப்படவில்லை. எந்த மொழியிலும் எந்த எழுத்திலும் புத்தகத்தை அனுப்புங்கள் — தமிழ், அரபு, சீனம், சுவாஹிலி, எதுவும். தளம் உங்கள் உரையை நீங்கள் எழுதியதுபோலவே காட்டும்.

## முழு விதிகள்

விரிவான படிப்படியான விதிகளை [`pdf-library/README.md`](pdf-library/README.md) இல் படியுங்கள். அட்டைப் படமும் `meta.json`-ம் கட்டாயம்.
