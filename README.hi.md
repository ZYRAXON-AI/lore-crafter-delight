# लोर क्राफ्टर डिलाइट

> एक एनिमेटेड डिजिटल लाइब्रेरी — 60 पूर्ण लंबाई के उपन्यास, पढ़ें और सुनें।

**Live app**: https://lore-crafter-delight.lovable.app

## अपनी PDF या किताब कैसे जोड़ें

1. इस रिपॉज़िटरी को फ़ोर्क करें (या क्लोन करें)।
2. एक फ़ोल्डर बनाएँ: `pdf-library/<आपका-नाम>/`।
3. उसमें अपनी किताब (`book.txt`, `book.md` या `book.pdf`), `title` वाली `meta.json`, और एक कवर चित्र (`cover.png` / `cover.svg`) रखें।
4. कमिट करें और एक Pull Request खोलें।
5. ऑटो-मर्ज बॉट जाँच करता है और कुछ ही मिनटों में आपकी किताब साइट पर दिख जाती है — कोई रीडिप्लॉय नहीं।

## किसी भी भाषा में लिखें

आप बांग्ला या अंग्रेज़ी तक सीमित नहीं हैं। किसी भी भाषा और किसी भी लिपि में किताब भेजें — हिन्दी, अरबी, चीनी, स्वाहिली, जो भी हो। साइट आपका पाठ वैसा ही दिखाती है जैसा आपने लिखा।

## पूरे नियम

विस्तृत चरण-दर-चरण नियम पढ़ें [`pdf-library/README.md`](pdf-library/README.md) में। कवर चित्र और `meta.json` अनिवार्य हैं।
