# Lore Crafter Delight

> Eine animierte digitale Bibliothek — 60 vollständige Romane zum Lesen und Hören.

**Live app**: https://lore-crafter-delight.lovable.app

## So fügst du dein PDF oder Buch hinzu

1. Forke dieses Repository (oder klone es).
2. Erstelle einen Ordner: `pdf-library/<dein-name>/`.
3. Lege darin dein Buch (`book.txt`, `book.md` oder `book.pdf`), eine `meta.json` mit `title` und ein Titelbild (`cover.png` / `cover.svg`) ab.
4. Committe und öffne einen Pull Request.
5. Der Auto-Merge-Bot prüft ihn, und dein Buch erscheint in Minuten auf der Website — ohne erneutes Deployment.

## Schreibe in jeder Sprache

Du bist nicht auf Bengalisch oder Englisch beschränkt. Reiche ein Buch in jeder Sprache und Schrift ein — Deutsch, Arabisch, Chinesisch, Suaheli, was auch immer. Die Website zeigt deinen Text genau so, wie du ihn geschrieben hast.

## Vollständige Regeln

Lies die ausführlichen Schritt-für-Schritt-Regeln in [`pdf-library/README.md`](pdf-library/README.md). Titelbild und `meta.json` sind Pflicht.
