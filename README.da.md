# Lore Crafter Delight

> Et animeret digitalt bibliotek — 60 fulde romaner at læse og lytte til.

**Live app**: https://lore-crafter-delight.lovable.app

## Sådan tilføjer du din PDF eller bog

1. Fork dette repository (eller klon det).
2. Opret en mappe: `pdf-library/<dit-navn>/`.
3. Læg din bog (`book.txt`, `book.md` eller `book.pdf`), en `meta.json` med `title` og et coverbillede (`cover.png` / `cover.svg`) i den.
4. Commit og åbn en Pull Request.
5. Auto-merge-botten tjekker den, og din bog vises på sitet inden for minutter — uden ny deploy.

## Skriv på ethvert sprog

Du er ikke begrænset til bengali eller engelsk. Indsend en bog på ethvert sprog og skriftsystem — dansk, arabisk, kinesisk, swahili, hvad som helst. Sitet viser din tekst præcis, som du skrev den.

## Fulde regler

Læs de detaljerede trin-for-trin-regler i [`pdf-library/README.md`](pdf-library/README.md). Coverbillede og `meta.json` er obligatoriske.
