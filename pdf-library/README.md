# pdf-library — যে কেউ এখানে নিজের বই জমা দিতে পারেন

এই ফোল্ডারটাই লাইব্রেরির দরজা। আপনি (বা আপনার এজেন্ট) এখানে একটা ফোল্ডার
বানিয়ে সেখানে আপনার বই রাখলেই, আমাদের সিস্টেম সেটা পড়ে ওয়েবসাইটে দেখিয়ে দেয় —
কোনো রিবিল্ড, ডিপ্লয় বা ম্যানুয়াল কাজ ছাড়াই।

**দুটো নিয়ম কড়া: (১) `meta.json` বাধ্যতামূলক, আর (২) একটি কভার ছবি বাধ্যতামূলক।**
বইয়ের টেক্সট বা PDF-ও থাকতে হবে — এই তিনটি ছাড়া জমা গ্রহণ করা হয় না।

> 🌍 **যেকোনো ভাষায় লিখুন।** আপনি শুধু বাংলা বা ইংরেজিতে সীমাবদ্ধ নন — যে কোনো ভাষায় ও
> লিপিতে (`meta.json`-এ `"language"` ফিল্ডে আপনার ভাষার নাম লিখুন) বই জমা দিতে পারেন।
> ইংরেজি ছাড়া অন্য ৩৯টি ভাষায় সংক্ষিপ্ত নির্দেশনা রুটে আছে: `README.<lang>.md`
> (যেমন [`README.hi.md`](../README.hi.md))।

## ধাপে ধাপে জমা

### ধাপ ১ — রিপো fork করুন

GitHub-এ ওপরের ডানে **Fork** চাপুন। তারপর fork-এর ভেতরে `pdf-library/` খুলুন।

### ধাপ ২ — নিজের নামে সাব-ফোল্ডার খুলুন

`pdf-library/`-এর ভেতরে আপনার বইয়ের নামে একটা সাব-ফোল্ডার তৈরি করুন। নাম দিন
ছোট হাতের ইংরেজিতে, শব্দের মাঝে হাইফেন (`-`)। যেমন `amar-voy`।

### ধাপ ৩ — `meta.json` অবশ্যই রাখুন

এই ফাইলটি বাধ্যতামূলক। নাম হতে হবে ঠিক `meta.json` (বা `metadata.json` /
`book.json`)। এর ভেতর অন্তত `title` থাকতে হবে:

```json
{
  "title": "আমার ভয়",
  "author": "আপনার নাম",
  "genre": "ভূত",
  "description": "দুই-তিন লাইনে বইয়ের পরিচিতি।",
  "cover_url": "",
  "language": "বাংলা"
}
```

| ফিল্ড         | বাধ্যতামূলক | বিবরণ                                                                                                                   |
| ------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------- |
| `title`       | **হ্যাঁ**   | বইয়ের সঠিক নাম                                                                                                          |
| `author`      | না          | না দিলে "নাম না জানা লেখক"                                                                                              |
| `genre`       | না          | `ভূত`, `প্রেম`, `রহস্য`, `ফ্যান্টাসি`, `অভিযান`, `বিজ্ঞান কল্পকাহিনি`, `হরর-রোম্যান্স`, `হাস্যরস`, `সামাজিক`, `অন্যান্য` |
| `description` | না          | বইয়ের সংক্ষিপ্ত পরিচিতি; না দিলে লেখা থেকে নেওয়া হয়                                                                   |
| `cover_url`   | না          | অনলাইনে ছবির লিংক; খালি রাখলে ফোল্ডারের `cover.*`/`icon.*` ব্যবহার হবে                                                  |
| `language`    | না          | `বাংলা` বা `English` (ডিফল্ট `বাংলা`)                                                                                   |

> `meta.json`-এ আপনি `cover` বা `lang` ছোট নামেও লিখতে পারেন — দুটোই কাজ করে।

### ধাপ ৪ — বই ও কভার ছবি দিন

**কভার ছবি বাধ্যতামূলক।** ফোল্ডারে অবশ্যই একটি ছবি থাকতে হবে, নাম হবে:

```
cover.png   /   cover.jpg   /   cover.jpeg   /   cover.webp   /   cover.svg   /   cover.gif
icon.png    /   icon.svg    /   icon.jpg
```

ছবিটির সঠিক নাম (`cover.*` বা `icon.*`) দিতে ভুলবেন না — নাহলে সেটি কভার হিসেবে
গণ্য হবে না। অনুপাত প্রায় **৩২০ × ৫১২** (খাড়া) সবচেয়ে ভালো দেখায়।
চাইলে `meta.json`-এ `cover_url` দিয়ে অনলাইনের ছবির লিংকও দিতে পারেন; তখন আর
ফোল্ডারে ছবি রাখতে হবে না।

**বইয়ের ফাইলও বাধ্যতামূলক।** নাম গুরুত্বপূর্ণ:

| ধরন            | গ্রহণযোগ্য ফাইলের নাম                                                            |
| -------------- | -------------------------------------------------------------------------------- |
| বইয়ের লেখা    | `book.txt`, `book.md`, `manuscript.txt`                                          |
| PDF            | `book.pdf`                                                                       |
| EPUB           | `book.epub`                                                                      |
| প্রচ্ছদ / আইকন | `cover.svg`, `cover.png`, `cover.jpg`, `cover.jpeg`, `cover.webp`, `cover.gif`, `icon.svg`, `icon.png`, `icon.jpg` |

- **`book.txt` / `book.md` থাকলে** — ওয়েবসাইটে অধ্যায় ভাগ করে সুন্দরভাবে পড়া যাবে
  (অনলাইন পড়ার আসল অভিজ্ঞতা)।
- **শুধু `book.pdf` / `book.epub` থাকলে** — বইটির কার্ড আসবে, প্রচ্ছদ ও টাইটেল
  সিস্টেমের তৈরি, আর একটি **সরাসরি পড়ুন/ডাউনলোড করুন** লিংক থাকবে।
- **একসাথে টেক্সট ও PDF রাখলে** — অনলাইনে পড়া হবে টেক্সট থেকে, আর PDF-ও ডাউনলোড করা যাবে।

অধ্যায় শুরু করুন এভাবে (বাংলা বা ইংরেজি দুই-ই চলে):

```
অধ্যায় ১: শুরু
প্রথম অনুচ্ছেদ...

দ্বিতীয় অনুচ্ছেদ...

Chapter 2: পরে
...
```

### ধাপ ৫ — Pull Request খুলুন

```sh
git checkout -b add-book-amar-voy
git add pdf-library/amar-voy
git commit -m "বই জমা: আমার ভয়"
git push origin add-book-amar-voy
```

তারপর GitHub-এ গিয়ে একটি **Pull Request** খুলুন `main`-এর দিকে।

### ধাপ ৬ — স্বয়ংক্রিয় প্রকাশ

`Auto-merge library submissions` ওয়ার্কফ্লো যাচাই করে:

- সব পরিবর্তন `pdf-library/` (বা পুরনো `books-submission/`) ফোল্ডারের ভিতরে কি না,
- প্রতিটি জমা-ফোল্ডারে `meta.json` আছে কি না এবং তার `title` পূরণ করা কি না,
- প্রতিটি ফোল্ডারে একটি কভার ছবি (`cover.*`/`icon.*`) বা `cover_url` আছে কি না,
- অন্তত একটি বই-ফাইল (`.txt/.md/.pdf/.epub`) আছে কি না।

সব ঠিক থাকলে PR-এ `submission` লেবেল লাগিয়ে **squash-merge** করে দেয়।
মার্জ হওয়ামাত্র লাইব্রেরি GitHub থেকে সরাসরি `pdf-library/` পড়ে বইটি দেখায় —
কোনো রিবিল্ড লাগে না।

## API দিয়ে জমা (এজেন্টের জন্য)

ফোল্ডার ছাড়া সরাসরি পাঠাতে চাইলে `POST /api/books` ব্যবহার করুন:

```sh
curl -X POST https://<your-site>/api/books \
  -H 'content-type: application/json' \
  -d '{
    "title": "আমার ভয়",
    "author": "আপনার নাম",
    "genre": "ভূত",
    "description": "একটি ছোট পরিচিতি।",
    "coverUrl": "https://example.com/cover.jpg",
    "book": "অধ্যায় ১: শুরু\n\nপ্রথম অনুচ্ছেদ...\n\nঅধ্যায় ২: অন্ধকার\n\n..."
  }'
```

`book`-এর বদলে `chapters` তালিকা, আর চাইলে `coverUrl`-ও দেওয়া যায়। শুধু `book`
দিলেও চলে — API নিজেই বাকি তথ্য বানিয়ে `meta.json` তৈরি করে। সার্ভারে
`GITHUB_TOKEN` থাকলে API নিজেই `pdf-library/<slug>/` ব্রাঞ্চে ফাইল কমিট করে একটি
**Pull Request** খোলে; তারপর অটো-মার্জ ওয়ার্কফ্লো সেটি মার্জ করে দেয়。

| উত্তর ফিল্ড   | অর্থ                                                |
| ------------- | --------------------------------------------------- |
| `ok`          | জমা গ্রহণ করা হয়েছে কিনা                           |
| `committed`   | GitHub-এ সত্যিই কমিট হয়েছে কিনা                    |
| `pullRequest` | খোলা PR-এর লিংক (সফল হলে)                           |
| `files`       | কমিট করার মতো ফাইল (টোকেন ছাড়া বা লেখা ব্যর্থ হলে) |
| `slug`        | ফোল্ডারের নাম                                       |
| `wordCount`   | যাচাই করা শব্দসংখ্যা                                |

## স্বয়ংক্রিয় প্রকাশ কীভাবে কাজ করে (সারসংক্ষেপ)

1. আপনি `pdf-library/<your-book>/` নিয়ে PR খোলেন — `meta.json` ও অন্তত একটা বই-ফাইল সহ।
2. `auto-merge-submission.yml` সব শর্ত যাচাই করে।
3. ঠিক থাকলে PR squash-merge হয়ে যায়, আর বইটি সঙ্গে সঙ্গে সাইটে দেখা যায়।

> পুরনো `books-submission/` ফোল্ডারও এখনো পড়া হয়, তাই আগের জমাগুলো হারায় না।
