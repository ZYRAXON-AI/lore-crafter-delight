# Lore Crafter Delight

> 애니메이션 디지털 도서관 — 읽고 들을 수 있는 장편소설 60편.

**Live app**: https://lore-crafter-delight.lovable.app

## PDF 또는 책을 추가하는 방법

1. 이 저장소를 포크(또는 클론)합니다.
2. 폴더를 만듭니다: `pdf-library/<이름>/`.
3. 그 안에 책(`book.txt`, `book.md`, `book.pdf`), `title`이 있는 `meta.json`, 표지 이미지(`cover.png` / `cover.svg`)를 넣습니다.
4. 커밋하고 Pull Request를 엽니다.
5. 자동 병합 봇이 확인하고 몇 분 안에 책이 사이트에 나타납니다 — 재배포가 필요 없습니다.

## 어떤 언어로든 쓰세요

벵골어나 영어로 제한되지 않습니다. 어떤 언어와 문자로든 책을 보내세요 — 한국어, 아랍어, 중국어, 스와힐리어 무엇이든. 사이트는 쓴 그대로 보여 줍니다.

## 전체 규칙

자세한 단계별 규칙은 [`pdf-library/README.md`](pdf-library/README.md)를 읽어 보세요. 표지 이미지와 `meta.json`은 필수입니다.
