# বই জমা দেওয়ার নিয়ম (Community Book Submission)

আপনার নিজের লেখা বই এই লাইব্রেরিতে যোগ করতে চান? খুব সহজ। নিচের ধাপগুলো অনুসরণ করুন।

## ধাপ ১ — একটি ফোল্ডার খুলুন

`books-submission/` ফোল্ডারের ভেতর আপনার বইয়ের নামে একটি নতুন সাব-ফোল্ডার তৈরি করুন।
নাম হবে ছোট হাতের ইংরেজি অক্ষরে, শব্দের মাঝে হাইফেন (`-`)।

উদাহরণ: আপনার বইয়ের নাম যদি হয় "আমার ভয়", ফোল্ডারের নাম হবে `amar-voy`।

```
books-submission/
└── amar-voy/
    ├── meta.json
    ├── book.txt
    └── cover.jpg
```

## ধাপ ২ — মেটাডেটা লিখুন (`meta.json`)

আপনার ফোল্ডারে `meta.json` নামে একটি ফাইল বানিয়ে নিচের মতো লিখুন:

```json
{
  "title": "আমার ভয়",
  "author": "আপনার নাম",
  "genre": "ভূত",
  "description": "একটি ছোট পরিচিতি — গল্পটি কেমন, তা দুই-তিন লাইনে লিখুন।",
  "cover_url": "",
  "language": "বাংলা"
}
```

| ফিল্ড         | বাধ্যতামূলক | বিবরণ                                                                                               |
| ------------- | ----------- | --------------------------------------------------------------------------------------------------- |
| `title`       | হ্যাঁ       | বইয়ের সঠিক নাম                                                                                     |
| `author`      | হ্যাঁ       | লেখকের নাম                                                                                          |
| `genre`       | হ্যাঁ       | ঘরানা — যেমন `ভূত`, `প্রেম`, `রহস্য`, `ফ্যান্টাসি`, `অভিযান`, `বিজ্ঞান কল্পকাহিনি`, `হরর-রোম্যান্স` |
| `description` | হ্যাঁ       | বইয়ের সংক্ষিপ্ত পরিচিতি                                                                            |
| `cover_url`   | না          | অনলাইনে থাকা ছবির লিংক। খালি রাখলে ফোল্ডারের `cover.jpg` ব্যবহার হবে                                |
| `language`    | না          | `বাংলা` বা `English` (ডিফল্ট: `বাংলা`)                                                              |

## ধাপ ৩ — বই ও প্রচ্ছদ দিন

ফোল্ডারে রাখুন:

1. **বইয়ের টেক্সট** — `book.txt` নামে রাখুন। অধ্যায় শুরু করুন এভাবে:

   ```
   অধ্যায় ১: শুরু
   প্রথম অনুচ্ছেদ...

   দ্বিতীয় অনুচ্ছেদ...

   অধ্যায় ২: অন্ধকার
   ...
   ```

   (`Chapter 1: ...` ইংরেজিতেও কাজ করে।)

2. **প্রচ্ছদ** — `cover.jpg` (বা `.png`, `.jpeg`, `.webp`) নামে একটি ছবি রাখুন।

> **PDF সম্পর্কে:** `book.pdf` রাখলে সেটা ওয়েবসাইটে ডাউনলোডের জন্য থাকবে, কিন্তু
> অনলাইনে পড়ার জন্য টেক্সট লাগবে। তাই সবচেয়ে ভালো হয় `book.txt`-ও সঙ্গে রাখা।

## ধাপ ৪ — পুল রিকোয়েস্ট পাঠান

```sh
git checkout -b add-book-amar-voy
git add books-submission/amar-voy
git commit -m "বই যোগ: আমার ভয়"
git push origin add-book-amar-voy
```

তারপর GitHub-এ গিয়ে একটি **Pull Request** খুলুন `main` ব্রাঞ্চের দিকে।

## ধাপ ৫ — স্বয়ংক্রিয় প্রকাশ

আপনার PR-তে শুধু `books-submission/` ফোল্ডারের ফাইল থাকলে আর `meta.json` ঠিক থাকলে
`Auto-merge book submissions` ওয়ার্কফ্লো নিজেই PR-টি মার্জ করে দেয়। মার্জ হওয়ামাত্র
লাইব্রেরি GitHub থেকে সরাসরি বইটি পড়ে নেয় — কোনো ম্যানুয়াল কাজ বা রিবিল্ড লাগে না।

## চাইলে API দিয়ে জমা দিন

এজেন্ট বা স্ক্রিপ্ট থেকে ফোল্ডার না বানিয়ে সরাসরি বই পাঠাতে চাইলে
`POST /api/books` ব্যবহার করুন:

```sh
curl -X POST https://<your-site>/api/books \
  -H 'content-type: application/json' \
  -d '{
    "title": "আমার ভয়",
    "author": "আপনার নাম",
    "genre": "ভূত",
    "description": "একটি ছোট পরিচিতি।",
    "book": "অধ্যায় ১: শুরু\n\nপ্রথম অনুচ্ছেদ...\n\nঅধ্যায় ২: অন্ধকার\n\n..."
  }'
```

`book`-এর বদলে `chapters` তালিকাও দেওয়া যায়:

```json
{
  "chapters": [{ "title": "শুরু", "paragraphs": ["প্রথম অনুচ্ছেদ...", "দ্বিতীয় অনুচ্ছেদ..."] }]
}
```

সার্ভারে `GITHUB_TOKEN` থাকলে API নিজেই ব্রাঞ্চ বানিয়ে, ফাইল কমিট করে, একটি
পুল রিকোয়েস্ট খোলে — তারপর উপরের অটো-মার্জ ওয়ার্কফ্লো সেটি মার্জ করে দেয়।
টোকেন না থাকলে বা টোকেনে লেখার অনুমতি না থাকলে API যাচাই করা `meta.json` ও
`book.txt` ফেরত দেয়, যাতে আপনি নিজে কমিট করতে পারেন।

| উত্তর ফিল্ড   | অর্থ                                                |
| ------------- | --------------------------------------------------- |
| `ok`          | জমা গ্রহণ করা হয়েছে কিনা                           |
| `committed`   | GitHub-এ সত্যিই কমিট হয়েছে কিনা                    |
| `pullRequest` | খোলা PR-এর লিংক (সফল হলে)                           |
| `files`       | কমিট করার মতো ফাইল (টোকেন ছাড়া বা লেখা ব্যর্থ হলে) |
| `slug`        | ফোল্ডারের নাম                                       |
| `wordCount`   | যাচাই করা শব্দসংখ্যা                                |
