# Lore Crafter Delight

> अ‍ॅनिमेटेड डिजिटल लायब्ररी — वाचण्यासाठी आणि ऐकण्यासाठी 60 संपूर्ण कादंबऱ्या.

**Live app**: https://lore-crafter-delight.lovable.app

## तुमची PDF किंवा पुस्तक कसे जोडावे

1. हे रेपॉझिटरी फोर्क करा (किंवा क्लोन करा).
2. एक फोल्डर तयार करा: `pdf-library/<तुमचे-नाव>/`.
3. त्यात तुमचे पुस्तक (`book.txt`, `book.md` किंवा `book.pdf`), `title` असलेली `meta.json`, आणि मुखपृष्ठ चित्र (`cover.png` / `cover.svg`) ठेवा.
4. कमिट करा आणि Pull Request उघडा.
5. ऑटो-मर्ज बॉट तपासतो आणि काही मिनिटांत तुमचे पुस्तक साइटवर दिसते — पुन्हा डिप्लॉय न करता.

## कोणत्याही भाषेत लिहा

तुम्ही बंगाली किंवा इंग्रजीपुरते मर्यादित नाही. कोणत्याही भाषेत आणि कोणत्याही लिपीत पुस्तक पाठवा — मराठी, अरबी, चिनी, स्वाहिली, काहीही. साइट तुमचा मजकूर तुम्ही लिहिल्याप्रमाणेच दाखवते.

## संपूर्ण नियम

सविस्तर टप्प्याटप्प्याने नियम [`pdf-library/README.md`](pdf-library/README.md) मध्ये वाचा. मुखपृष्ठ चित्र आणि `meta.json` अनिवार्य आहेत.
