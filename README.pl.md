# Lore Crafter Delight

> Animowana biblioteka cyfrowa — 60 pełnych powieści do czytania i słuchania.

**Live app**: https://lore-crafter-delight.lovable.app

## Jak dodać swój PDF lub książkę

1. Zrób fork tego repozytorium (lub sklonuj je).
2. Utwórz folder: `pdf-library/<twoja-nazwa>/`.
3. Umieść w nim swoją książkę (`book.txt`, `book.md` lub `book.pdf`), plik `meta.json` z polem `title` oraz obraz okładki (`cover.png` / `cover.svg`).
4. Zatwierdź zmiany i otwórz Pull Request.
5. Bot automatycznego scalania sprawdzi je, a twoja książka pojawi się na stronie w kilka minut — bez ponownego wdrożenia.

## Pisz w dowolnym języku

Nie jesteś ograniczony do bengalskiego ani angielskiego. Prześlij książkę w dowolnym języku i piśmie — polskim, arabskim, chińskim, suahili, jakimkolwiek. Strona pokazuje twój tekst dokładnie tak, jak go napisałeś.

## Pełne zasady

Przeczytaj szczegółowe zasady krok po kroku w [`pdf-library/README.md`](pdf-library/README.md). Obraz okładki i `meta.json` są obowiązkowe.
