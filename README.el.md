# Lore Crafter Delight

> Μια κινούμενη ψηφιακή βιβλιοθήκη — 60 ολόκληρα μυθιστορήματα για ανάγνωση και ακρόαση.

**Live app**: https://lore-crafter-delight.lovable.app

## Πώς να προσθέσετε το PDF ή το βιβλίο σας

1. Κάντε fork αυτού του αποθετηρίου (ή κλωνοποιήστε το).
2. Δημιουργήστε έναν φάκελο: `pdf-library/<το-όνομά-σας>/`.
3. Βάλτε μέσα το βιβλίο σας (`book.txt`, `book.md` ή `book.pdf`), ένα `meta.json` με `title` και μια εικόνα εξωφύλλου (`cover.png` / `cover.svg`).
4. Κάντε commit και ανοίξτε ένα Pull Request.
5. Το bot αυτόματης συγχώνευσης το ελέγχει και το βιβλίο σας εμφανίζεται στον ιστότοπο σε λίγα λεπτά — χωρίς νέα ανάπτυξη.

## Γράψτε σε οποιαδήποτε γλώσσα

Δεν περιορίζεστε στα βεγγαλικά ή τα αγγλικά. Υποβάλετε βιβλίο σε οποιαδήποτε γλώσσα και γραφή — ελληνικά, αραβικά, κινεζικά, σουαχίλι, ό,τι θέλετε. Ο ιστότοπος δείχνει το κείμενό σας ακριβώς όπως το γράψατε.

## Πλήρεις κανόνες

Διαβάστε τους αναλυτικούς κανόνες βήμα προς βήμα στο [`pdf-library/README.md`](pdf-library/README.md). Η εικόνα εξωφύλλου και το `meta.json` είναι υποχρεωτικά.
