# Lore Crafter Delight

> Thư viện số động — 60 tiểu thuyết trọn vẹn để đọc và nghe.

**Live app**: https://lore-crafter-delight.lovable.app

## Cách thêm PDF hoặc sách của bạn

1. Fork kho lưu trữ này (hoặc clone).
2. Tạo thư mục: `pdf-library/<tên-của-bạn>/`.
3. Đặt vào đó sách của bạn (`book.txt`, `book.md` hoặc `book.pdf`), một `meta.json` có `title`, và ảnh bìa (`cover.png` / `cover.svg`).
4. Commit và mở Pull Request.
5. Bot tự động hợp nhất kiểm tra và sách của bạn xuất hiện trên trang trong vài phút — không cần triển khai lại.

## Viết bằng bất kỳ ngôn ngữ nào

Bạn không bị giới hạn ở tiếng Bengal hay tiếng Anh. Hãy gửi sách bằng bất kỳ ngôn ngữ và chữ viết nào — Việt, Ả Rập, Trung, Swahili, gì cũng được. Trang hiển thị văn bản của bạn đúng như bạn viết.

## Toàn bộ quy tắc

Đọc quy tắc từng bước tại [`pdf-library/README.md`](pdf-library/README.md). Ảnh bìa và `meta.json` là bắt buộc.
