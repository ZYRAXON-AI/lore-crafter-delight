# Lore Crafter Delight

> Animoitu digitaalinen kirjasto — 60 kokonaista romaania luettavaksi ja kuunneltavaksi.

**Live app**: https://lore-crafter-delight.lovable.app

## Näin lisäät PDF:n tai kirjasi

1. Haarauta (fork) tämä repositorio tai kloonaa se.
2. Luo kansio: `pdf-library/<nimesi>/`.
3. Laita siihen kirjasi (`book.txt`, `book.md` tai `book.pdf`), `meta.json`, jossa on `title`, ja kansikuva (`cover.png` / `cover.svg`).
4. Commitoi ja avaa Pull Request.
5. Automaattinen yhdistämisbotti tarkistaa sen, ja kirjasi ilmestyy sivustolle minuuteissa — ilman uutta julkaisua.

## Kirjoita millä tahansa kielellä

Et ole rajoittunut bengaliin tai englantiin. Lähetä kirja millä tahansa kielellä ja kirjoitusjärjestelmällä — suomeksi, arabiaksi, kiinaksi, swahiliksi, millä tahansa. Sivusto näyttää tekstisi täsmälleen sellaisena kuin kirjoitit sen.

Lue yksityiskohtaiset vaiheittaiset säännöt tiedostosta [`pdf-library/README.md`](pdf-library/README.md). Kansikuva ja `meta.json` ovat pakollisia.
