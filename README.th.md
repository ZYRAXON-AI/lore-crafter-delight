# Lore Crafter Delight

> หอสมุดดิจิทัลแบบแอนิเมชัน — นวนิยายเต็มเล่ม 60 เรื่อง อ่านและฟังได้

**Live app**: https://lore-crafter-delight.lovable.app

## วิธีเพิ่ม PDF หรือหนังสือของคุณ

1. Fork ที่เก็บนี้ (หรือโคลน)
2. สร้างโฟลเดอร์: `pdf-library/<ชื่อของคุณ>/`
3. ใส่หนังสือของคุณ (`book.txt`, `book.md` หรือ `book.pdf`), `meta.json` ที่มี `title`, และภาพปก (`cover.png` / `cover.svg`)
4. คอมมิตและเปิด Pull Request
5. บอตผสานอัตโนมัติจะตรวจสอบ และหนังสือของคุณจะปรากฏบนเว็บไซต์ภายในไม่กี่นาที — ไม่ต้องดีพลอยใหม่

## เขียนได้ทุกภาษา

คุณไม่ได้จำกัดแค่บังกลาหรืออังกฤษ ส่งหนังสือได้ทุกภาษาและทุกอักษร — ไทย จีน อาหรับ สวาฮิลี อะไรก็ได้ เว็บไซต์แสดงข้อความของคุณตามที่คุณเขียนไว้ทุกประการ

## กฎทั้งหมด

อ่านกฎแบบทีละขั้นได้ที่ [`pdf-library/README.md`](pdf-library/README.md) ภาพปกและ `meta.json` เป็นสิ่งบังคับ
