# Lore Crafter Delight

> Pustaka digital beranimasi — 60 novel penuh untuk dibaca dan didengar.

**Live app**: https://lore-crafter-delight.lovable.app

## Cara menambah PDF atau buku anda

1. Fork repositori ini (atau klon).
2. Cipta folder: `pdf-library/<nama-anda>/`.
3. Di dalamnya letakkan buku anda (`book.txt`, `book.md` atau `book.pdf`), `meta.json` dengan `title`, dan imej kulit (`cover.png` / `cover.svg`).
4. Commit dan buka Pull Request.
5. Bot gabung automatik menyemaknya dan buku anda muncul di laman dalam beberapa minit — tanpa deploy semula.

## Tulis dalam mana-mana bahasa

Anda tidak terhad kepada bahasa Bengali atau Inggeris. Hantar buku dalam mana-mana bahasa dan tulisan — Melayu, Arab, Cina, Swahili, apa sahaja. Laman memaparkan teks anda tepat seperti yang anda tulis.

## Peraturan penuh

Baca peraturan langkah demi langkah di [`pdf-library/README.md`](pdf-library/README.md). Imej kulit dan `meta.json` wajib.
