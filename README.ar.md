# لور كرافتر ديليت

> مكتبة رقمية متحركة — 60 رواية كاملة يمكنك قراءتها والاستماع إليها.

**Live app**: https://lore-crafter-delight.lovable.app

## كيف تضيف ملف PDF أو كتابك

1. انسخ هذا المستودع (Fork) أو استنسخه (Clone).
2. أنشئ مجلدًا: `pdf-library/<اسمك>/`.
3. ضع داخله كتابك (`book.txt` أو `book.md` أو `book.pdf`)، وملف `meta.json` يحتوي على `title`، وصورة غلاف (`cover.png` / `cover.svg`).
4. ثبّت التغييرات وافتح Pull Request.
5. يتحقق روبوت الدمج التلقائي ويظهر كتابك على الموقع خلال دقائق — دون إعادة نشر.

## اكتب بأي لغة

لست محصورًا بالبنغالية أو الإنجليزية. أرسل كتابك بأي لغة وأي كتابة — العربية أو الهندية أو الصينية أو السواحيلية، أيًّا كانت. يعرض الموقع نصك تمامًا كما كتبته.

## القواعد الكاملة

اقرأ القواعد التفصيلية خطوة بخطوة في [`pdf-library/README.md`](pdf-library/README.md). صورة الغلاف و`meta.json` إلزاميان.
