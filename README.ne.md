# लोर क्राफ्टर डिलाइट

> एक एनिमेटेड डिजिटल पुस्तकालय — पढ्न र सुन्न ६० पूर्ण उपन्यास।

**Live app**: https://lore-crafter-delight.lovable.app

## आफ्नो PDF वा पुस्तक कसरी थप्ने

१. यो रिपोजिटरी फोर्क गर्नुहोस् (वा क्लोन गर्नुहोस्)।
२. एउटा फोल्डर बनाउनुहोस्: `pdf-library/<तपाईंको-नाम>/`।
३. त्यसमा आफ्नो पुस्तक (`book.txt`, `book.md` वा `book.pdf`), `title` सहितको `meta.json`, र आवरण तस्बिर (`cover.png` / `cover.svg`) राख्नुहोस्।
४. कमिट गरेर Pull Request खोल्नुहोस्।
५. स्वतः-मर्ज बोटले जाँच्छ र केही मिनेटमै तपाईंको पुस्तक साइटमा देखिन्छ — पुनः डिप्लोय चाहिँदैन।

## कुनै पनि भाषामा लेख्नुहोस्

तपाईं बंगाली वा अंग्रेजीमा सीमित हुनुहुन्न। कुनै पनि भाषा र लिपिमा पुस्तक पठाउनुहोस् — नेपाली, अरबी, चिनियाँ, स्वाहिली, जे पनि। साइटले तपाईंको पाठ ठ्याक्कै लेखेझैं देखाउँछ।

## पूरा नियम

विस्तृत चरणबद्ध नियम [`pdf-library/README.md`](pdf-library/README.md) मा पढ्नुहोस्। आवरण तस्बिर र `meta.json` अनिवार्य छन्।
