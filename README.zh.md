# Lore Crafter Delight

> 一座动画数字图书馆 — 60 部完整长篇小说，可读可听。

**Live app**: https://lore-crafter-delight.lovable.app

## 如何添加你的 PDF 或书籍

1. 复刻（Fork）本仓库，或克隆它。
2. 创建一个文件夹：`pdf-library/<你的名字>/`。
3. 在其中放入你的书（`book.txt`、`book.md` 或 `book.pdf`）、含有 `title` 的 `meta.json`，以及一张封面图（`cover.png` / `cover.svg`）。
4. 提交并打开 Pull Request。
5. 自动合并机器人会检查，几分钟内你的书就会出现在网站上 — 无需重新部署。

## 用任何语言写作

你不限于孟加拉语或英语。用任何语言、任何文字提交书籍 — 中文、阿拉伯语、斯瓦希里语等等均可。网站会原样显示你写下的文字。

## 完整规则

在 [`pdf-library/README.md`](pdf-library/README.md) 中阅读详细的分步规则。封面图和 `meta.json` 为必需。
