# লোর ক্রাফটার ডিলাইট

> একটি অ্যানিমেটেড ডিজিটাল লাইব্রেরি — ৬০টি পূর্ণদৈর্ঘ্য উপন্যাস, পড়া ও শোনা যায়।

**Live app**: https://lore-crafter-delight.lovable.app

## আপনার PDF বা বই কীভাবে যোগ করবেন

১. এই রিপোজিটরি ফর্ক করুন (বা ক্লোন করুন)।
২. একটি ফোল্ডার বানান: `pdf-library/<আপনার-নাম>/`।
৩. সেখানে রাখুন আপনার বই (`book.txt`, `book.md` বা `book.pdf`), `title`-সহ একটি `meta.json`, আর একটি কভার ছবি (`cover.png` / `cover.svg`)।
৪. কমিট করে একটি Pull Request খুলুন।
৫. অটো-মার্জ বট যাচাই করে কয়েক মিনিটেই আপনার বই সাইটে দেখাবে — রিডিপ্লয় লাগবে না।

## যেকোনো ভাষায় লিখুন

আপনি শুধু বাংলা বা ইংরেজিতে সীমাবদ্ধ নন। যেকোনো ভাষায় ও যেকোনো লিপিতে বই জমা দিন — বাংলা, হিন্দি, আরবি, চীনা, সোয়াহিলি, যা-ই হোক। সাইটে আপনার লেখা ঠিক যেমন লিখেছেন তেমনই দেখাবে।

## সম্পূর্ণ নিয়ম

ধাপে ধাপে বিস্তারিত নিয়ম পড়ুন [`pdf-library/README.md`](pdf-library/README.md)-এ। কভার ছবি ও `meta.json` বাধ্যতামূলক।
