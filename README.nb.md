# Lore Crafter Delight

> Et animert digitalt bibliotek — 60 hele romaner å lese og lytte til.

**Live app**: https://lore-crafter-delight.lovable.app

## Slik legger du til din PDF eller bok

1. Fork dette repoet (eller klon det).
2. Lag en mappe: `pdf-library/<ditt-navn>/`.
3. Legg boken din (`book.txt`, `book.md` eller `book.pdf`), en `meta.json` med `title` og et omslagsbilde (`cover.png` / `cover.svg`) i den.
4. Commit og åpne en Pull Request.
5. Auto-merge-boten sjekker den, og boken din vises på nettstedet i løpet av minutter — uten ny utrulling.

## Skriv på hvilket som helst språk

Du er ikke begrenset til bengali eller engelsk. Send inn en bok på hvilket som helst språk og skriftsystem — norsk, arabisk, kinesisk, swahili, hva som helst. Nettstedet viser teksten din akkurat som du skrev den.

## Fullstendige regler

Les de detaljerte trinnvise reglene i [`pdf-library/README.md`](pdf-library/README.md). Omslagsbilde og `meta.json` er obligatoriske.
