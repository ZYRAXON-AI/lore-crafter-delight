# لور كرافٹر ڈیلائٹ

> ایک متحرک ڈیجیٹل لائبریری — 60 مکمل ناول، پڑھیں اور سنیں۔

**Live app**: https://lore-crafter-delight.lovable.app

## اپنی PDF یا کتاب کیسے شامل کریں

1. اس ریپوزٹری کو فورک کریں (یا کلون کریں)۔
2. ایک فولڈر بنائیں: `pdf-library/<آپ-کا-نام>/`۔
3. اس میں اپنی کتاب (`book.txt`، `book.md` یا `book.pdf`)، `title` کے ساتھ `meta.json` اور ایک سرورق تصویر (`cover.png` / `cover.svg`) رکھیں۔
4. کمٹ کریں اور Pull Request کھولیں۔
5. آٹو مرج بوٹ جانچ کرتا ہے اور کچھ منٹوں میں آپ کی کتاب سائٹ پر آ جاتی ہے — کوئی دوبارہ تعیناتی نہیں۔

## کسی بھی زبان میں لکھیں

آپ بنگلہ یا انگریزی تک محدود نہیں۔ کسی بھی زبان اور کسی بھی رسم الخط میں کتاب جمع کرائیں — اردو، عربی، چینی، سواحلی، جو بھی۔ سائٹ آپ کا متن ویسا ہی دکھاتی ہے جیسا آپ نے لکھا۔

## مکمل قواعد

تفصیلی مرحلہ وار قواعد [`pdf-library/README.md`](pdf-library/README.md) میں پڑھیں۔ سرورق اور `meta.json` لازمی ہیں۔
